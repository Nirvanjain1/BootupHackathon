# GesturePlay – Gesture-Controlled Recreational Website

## About the Website

GesturePlay is a recreational and interactive website designed to support differently-abled individuals through gesture-controlled activities and exercises.

The website provides an accessible environment where users can play games, practice speaking, improve cognitive abilities, and perform various recreational exercises using simple hand gestures instead of traditional mouse and keyboard controls.

The main objective is to make digital entertainment and interactive exercises more **inclusive, engaging, and accessible**.

---

## Features

The website consists of multiple gesture-controlled activities:

### 1. Gesture-Controlled Document Reader
- Allows users to read documents using hand gestures.
- Supports gesture-based navigation through document pages.
- Makes document reading more interactive and accessible.

### 2. Gesture-Controlled Flappy Bird
- A gesture-controlled version of the classic Flappy Bird game.
- Players control the bird using hand movements.
- Provides an engaging recreational activity.

### 3. Math Quiz Game
- Presents basic math questions involving addition, subtraction, multiplication, and division.
- Users answer questions using hand gestures.
- Encourages mental calculation and cognitive engagement.

### 4. EchoRunner
- An interactive recreational game controlled through gestures.
- Provides an engaging gaming experience while encouraging coordination and interaction.

### 5. Speaking Exercises
- Provides speaking practice activities to encourage verbal communication.
- Helps users engage in interactive speaking exercises.

### 6. Simon Says
- An interactive game based on following instructions.
- Encourages attention, memory, and gesture recognition.
- Provides an entertaining way to practice coordination.

The project aims to combine technology, accessibility, and entertainment to create an inclusive digital platform.
