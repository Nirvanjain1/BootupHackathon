# HandWave

Control documents and games with hand gestures. Built for people who cannot easily use a mouse, keyboard or touchscreen.
Camera video is processed inside the browser and is never uploaded.

## Run
Open this folder in VS Code, install the Live Server extension, right-click `index.html` and choose "Open with Live Server" (Chrome or Edge, internet needed).
